# Findings log (append-only, newest last)

## E01 (results/e01) — synthetic demand panel, 4 teachers, 2 surrogate engines, SR-on-labels control
Setup: 40 series x 84 usable months; train t<60, test t>=78 (future), "ex" = 20 unseen series with level 1.5-2x higher (extrapolation). Oracle (true fn) R2 = 0.994 / 0.997.
F1. **Fusion works** (H3 supported): g(T(raw)) evaluated on raw columns equals g(z) composed with numeric T (max abs diff 1.5e-6; tests show 1e-9 for pure T). Fused formula runs 0.44 ms vs XGB 19 ms for 720 rows (~44x) with no ML dependency.
F2. **Transformation cost is non-trivial**: g has 187 nodes, fused F has 685 (T contributes ~3.6x). Supports a joint T+g complexity metric (candidate novelty). Fused expr also contains float noise like `+1.7e-20` from standardised sin() -> needs a clean-up/chop pass.
F3. **Extrapolation (H1 strongly supported)**: XGB/LGBM teacher R2 on out-of-range levels = 0.64 (RMSE 24) vs oracle 0.997; its best sparse symbolic surrogate (52 nodes vs 11,694 tree nodes) reaches 0.997 (RMSE 2.07). Trees saturate; equations extrapolate. MLP teacher also degrades (0.51) while its GP/sparse surrogates reach 0.97-0.99.
F4. **Fidelity != accuracy off-support**: the extrapolating surrogate has fidelity-R2 to the teacher of only 0.1-0.2 on "ex" — it is *better* than the teacher exactly where it disagrees with it. Fidelity-to-teacher is therefore the wrong objective outside the training support. Conceptual finding: what should a surrogate be faithful to? (-> new RQ8)
F5. **H2 NOT supported on this data**: sparse regression on raw labels (0.994 te / 0.997 ex at 44 nodes) matches distillation. Reason: truth lies inside the term library, noise is low (sd 2) and n is large. Distillation's advantage, if any, must be searched in low-n / high-noise / mis-specified-library regimes (-> E02).
F6. **METHOD BUG/WEAKNESS (mine)**: sparse path is erratic (te R2 0.46 at 133 nodes, MLP teacher -9.4). Cause: OLS "debias" on near-collinear library columns (roll3 = mean(l1,l2,l3); sin/cos pairs) -> exploding coefficients. Not a property of the idea; fix with ridge-debias/STLSQ + collinear pruning before drawing conclusions about sparse method.
F7. GP (gplearn) is noisy but yields very compact formulas (5-30 nodes, te R2 0.96-0.99 for lgbm/mlp teachers); fidelity 0.92-0.95. Augmented queries helped MLP teacher GP in extrapolation (0.97->0.99) but hurt xgb GP (0.98->0.27/0.74) -> high variance, needs multiple seeds.
Caveats: single seed; truth is inside the library (optimistic); synthetic only; no real data yet.

## E02 (results/e02) — regime sweep: truth {in-library, mis-specified} x noise sd {2,8,20} x #series {6,15,40} x 5 seeds, XGB teacher, repaired sparse engine
Metric: RMSE of each predictor against the NOISE-FREE truth (te = future periods, ex = unseen higher levels). Support chosen by validation on labels for all methods.
F8. **Repair confirmed (F6)**: with ridge-refit + collinearity pruning + validation-selected support the erratic behaviour disappears; sparse symbolic g has 11-250 nodes.
F9. **Symbolic g beats the XGB teacher against truth almost everywhere** (in-library: te RMSE 0.3-4.9 vs teacher 1.9-12; ex 0.4-6.7 vs 15-30). With a mis-specified library the gap narrows (te 3.5-9 vs 6-11; ex 6-14 vs 10-25) but largely persists. Equation class = better inductive bias for this smooth, extrapolating process.
F10. **H2 (distill > labels) mostly REJECTED**: plain distillation wins in 56% (te) / 68% (ex) of 90 runs with tiny median differences; the teacher is trained on the same labels, so it cannot add information, only smooth them.
F11. **Naive query augmentation HURTS** (wins only 29%/43%): I jittered standardized features z independently, producing off-manifold points (e.g. sin_m/cos_m inconsistent, mom != f(l1,l12)). Hypothesis H6: augmentation must be done in RAW space and passed through T so that queries lie on the feature manifold. -> E03.
F12. **Tail risk**: one mis-specified, 6-series, low-noise case gave ex-RMSE 48.9 for plain distill (median of others ~10) — polynomial/ratio terms can extrapolate catastrophically. Symbolic extrapolation is better on median but needs guardrails (domain checks, clipping, validation on shifted data). Need worst-case (not just median) reporting.
F13. Complexity is mostly selected by noise: 11-40 nodes at noise 20, 100-250 at misspec noise 2 (more terms to approximate a non-library function) — complexity grows as a symptom of library mis-specification; useful diagnostic (H7).
Caveat: all synthetic; library includes helpful features (log price, cyclic month, momentum) that I engineered — in real tasks T itself must be chosen.

## E03 (results/e03) — REAL monthly series: airline (144), car sales (108), CO2 (Mauna Loa, monthly), sunspots (last 600)
Hold-out = last 24 months (60 for sunspots); one-step (true lags) and recursive multi-step; baselines seasonal-naive, Holt-Winters (damped, mult. seasonal).
F14. **H1 confirmed on real data**: on trending series the XGB teacher fails to extrapolate (airline sMAPE 13.4%, CO2 1.33%) while its distilled symbolic surrogate gets airline 3.4% (one-step) / 4.9% (24-step recursive) and CO2 0.07% / 0.09%, vs Holt-Winters 8.4% / 0.08%. The symbolic formula (fused, raw-input) beats the black box and is competitive with the classical statistical benchmark. On non-trending sunspots symbolic ~ teacher (17.8 vs 19.2 sMAPE one-step), as expected (no extrapolation advantage).
F15. **Garbage-in-faithfully-out**: MLP teacher was untrained-quality (my bug: unscaled target; sMAPE 80-200%). The 8-14 node surrogate reproduced the failure (RMSE 394.7 vs teacher 394.7). Distillation preserves the teacher's errors, so teacher validity must be checked first. Output scaling is part of the pipeline T_out and must be compiled too (-> E04).
F16. **Raw-space jitter augmentation is not a safe fix for H6**: helped airline (rec sMAPE 4.4->3.1) but destroyed CO2 (0.09->1.2). Independent 3% jitter on lags breaks the strong lag correlation (CO2 lags differ by <1%), and a tree teacher's labels off-support are wrong anyway. Refined H6: augment only along the empirical manifold (e.g. noise in the residual space of an AR model / block bootstrap) and never rely on tree labels off-support.
F17. **Compactness fails on real small-n series**: validation-minimum selection yields fused formulas of 600-780 nodes (airline) — not interpretable. Need explicit complexity control (1-SE rule / Pareto front) — the joint fidelity-complexity objective of the plan is not optional. (-> E04)

## E04 (results/e04) — complexity control, repaired MLP teacher (scaled target), Pareto fronts, knee formulas
F18. **Validation-min / 1-SE selection is unreliable under non-stationarity**: it picked 645-665-node fused formulas on airline and an 8-node one for carsales; yet the Pareto front (pareto.csv) shows test error is FLAT after ~3-5 terms (airline: 3 terms/26 nodes = 2.84% sMAPE vs 3.3% at 645 nodes; CO2: 5 terms/40 nodes 0.08% = full; sunspots: 3 terms/42 nodes = 17.8% vs 16.4% best at 1000 nodes). Validation RMSE keeps falling with more terms while test does not improve (val window is earlier & dynamic differs). Carsales shows the opposite danger: >9 terms overfit catastrophically (rec sMAPE up to 175%). => model selection needs rolling-origin CV and/or MDL/BIC penalties (-> E05+).
F19. **Knee formulas are human-readable closed forms on RAW inputs** (results/e04/knee_formulas.md). Airline (3 terms):
     yhat = 49.8*ln(1+y[t-1]) + 126.4*ln(1+y[t-12])^2 - 1151.6*ln(1+y[t-12]) + 2509.3 — beats XGB (13.4% sMAPE) and Holt-Winters (8.4% rec.) with 2.8%/3.4%.
     CO2 (5 terms): trend via lag-1/6/12 logs + annual & semiannual sine terms. This is exactly the classical decomposition a forecaster would write — recovered automatically from a black box.
F20. **MLP teacher after target scaling is valid** (airline 17.2% vs XGB 13.4%; still can't extrapolate). Its surrogate again beats it (5.6%/8.4%) -> same F4 pattern (surrogate better than teacher off-support).
F21. Float residue like `5.2336e-17*...` persists in fused formulas -> add chop pass before presenting formulas (cosmetic but needed).
Status vs hypotheses: H1 confirmed (synthetic+real), H2 rejected, H3 confirmed, H6 refuted for naive aug, new H8: Pareto knee (3-5 terms) is a stable, dataset-independent structural property when features include log-lags & Fourier month terms.
Caveats: 4 series only; 1 teacher seed; test = last 24 months of a single origin (no rolling-origin); feature library hand-designed (log lags, Fourier month) — this is the strongest "prior" we inject and must be examined (-> ablation of library design).

## E05 (results/e05) — classification + real preprocessing pipeline (Titanic: median-impute, log1p, scale, one-hot; Breast-cancer: log1p+scale, 30 features)
F22. **Preprocessing compiles EXACTLY** (src/mt/compile_sklearn.py): SimpleImputer -> Piecewise(isnan), StandardScaler, log1p, OneHot (indicator on integer codes) reproduce sklearn's T with max abs error 0.0; final fused F(raw)=sigmoid(g(T(raw))) equals the g-on-z probabilities with max error 0.0 (all rows). H3/RQ2 confirmed for classification and mixed numeric/categorical/missing inputs. Fused node counts: T alone 179 (Titanic) / 240 (breast cancer) nodes — T is again a large share of the formula.
F23. **Boundary of closed form**: strings must be mapped to integer codes by a dictionary (lookup, outside F). Imputation needs an `isnan` primitive (non-algebraic but trivially implementable). Table-based transforms (quantile/rank/target encoding) are not closed-form -> E06b measures their cost.
F24. **Breast cancer**: 4-term sigmoid formula (26 fused nodes) AUC 0.984, acc 94% vs XGB 0.985 / MLP 0.995 — compact and near-teacher. BUT logistic regression on T(x) gets AUC 0.9955 / acc 97%: the "black box" is not better than a linear model here.
F25. **Titanic**: 43-term surrogate (1237 fused nodes) AUC 0.855 ~ XGB 0.861 ~ logistic regression 0.854; 8-term 0.838. Sign-agreement with teacher only 88-92%. Honest conclusion: where the teacher has no real non-linear signal, distillation just rediscovers logistic regression; symbolic value must be tested on tasks where teacher >> linear (-> E06).
F26. Recurrent pattern (F4/F20): MLP teacher (Titanic AUC 0.823) is WORSE than its own symbolic surrogate (0.866) — the equation class acts as a regulariser.

## E06 (results/e06) — (a) tasks where black box >> logistic regression; (b) preprocessing expressibility cost
F27. **Non-linear gain is retained by compact equations when the library contains the structure**: circles(+3 noise dims): logreg AUC 0.47, XGB 0.999, sparse symbolic 0.998 (12 terms/50 nodes; 6 terms/26 nodes from MLP: 0.999). xor-quad(6d): symbolic 0.935-0.950 vs XGB 0.924 / MLP 0.903 (symbolic > teacher again, F4/F26).
F28. **Library mis-specification is detectable and fatal for sparse-poly**: moons: deg-2 library = logreg level (0.92) vs MLP 0.978; GP (sin/cos/sqrt/div) <- MLP recovers 0.978 with 49 nodes and 97% sign-agreement. sin-abs-prod(8d): sparse 0.90 vs teacher 0.93-0.95; GP 0.80-0.84. => no single engine wins; need engine portfolio + diagnostic (fidelity plateau / node growth, cf. F13).
F29. **Preprocessing taxonomy (E06b)**: PCA (4 comps from 6 dims incl. scaling) closed form 80 nodes, err 1e-15; PolynomialFeatures exact 21 nodes; **QuantileTransformer is exactly representable (err 1e-16) only as piecewise-linear tables: 510 / 2670 / 10770 nodes for n_quantiles 10/50/200** — the transformation cost can dwarf the model (g has 10-100 nodes). Implication: choose transformations by compile cost, or replace table transforms by smooth parametric ones (log, Box-Cox) before distillation. Candidate contribution: a "compilation-aware preprocessing" principle.

## E07 (results/e07) — 7 real monthly series, rolling-origin-CV 1-SE selection, library ablation, one-step (24 pts) + 12-step recursive from 2 origins
**CORRECTION to F14/F19**: the claim "symbolic beats Holt-Winters" came from E03's single-origin 24-step horizon (HW 8.4% on airline). With 12-step horizons from two origins HW wins on 5/7 series (airline 4.1 vs 7.2; co2 0.06 vs 0.09; meantemp 3.6 vs 4.4; robberies 11.4 vs 13.2; writingpaper 18.2 vs 20.0); symbolic wins on carsales and sunspots. Correct statement: **symbolic fused formulas are competitive with, not better than, classical ETS.**
F30. vs XGB teacher (full library): symbolic wins 5/7 (one-step) and 5/7 (12-step recursive); biggest gains on trending/extrapolating series (airline, co2, robberies). Loses where seasonality is multiplicative-nonlinear (carsales one-step, writingpaper).
F31. **H2 firmly rejected for forecasting**: sym[distill] vs sym[labels] identical to 2 decimals on 7 series (e.g. airline 4.44/4.43). Teacher trained on the same labels adds no information; the benefit comes from the equation class, not from distillation.
F32. **Library prior dominates**: nofourier (log lags, month only linear) gave 4.86% rec12 / 26 nodes on airline vs full library 7.24% / 220 nodes; nolog best on robberies/sunspots. No library is uniformly best; 1-SE rolling-origin CV still selects 100-500-node formulas for the full library (airline 220, writingpaper 508) -> need stronger complexity penalty / MDL.
F33. Sunspots (non-trending cycle): nothing beats ~21-24% one-step; nodes 11-42 chosen; confirms no extrapolation advantage where none is needed.
Honest summary so far: (1) fusion works and is exact (F1,F22); (2) compact equations frequently match/beat black-box teachers, especially off-support (F3,F14,F30); (3) but distillation per se is not what delivers it (F10,F31); (4) classical statistical baselines remain strong; (5) preprocessing compile cost can dominate (F2,F29).
Open: when does teacher-queried distillation add real information? Theory says: only with abundant on-manifold queries and small/noisy label sets -> E08 (Feynman-style laws with known truth, MLP teacher, 200 noisy labels vs 5000 teacher queries).

## E08 / E08b (results/e08, e08b) — Feynman-style laws, MLP teacher on n=200 noisy labels (noise 5% of sd), GP (gplearn) on labels vs 5000 on-manifold teacher queries; 9 laws x 2 seeds
Scoring = R2 against the NOISE-FREE true law, in-range and on a 1.5x extrapolation box.
F34. **Search representation matters enormously (E08 vs E08b)**: GP in the teacher's standardized z-space: mean in-range R2 0.68 (newton_grav 0.53, ideal_gas 0.70). Same GP on RAW units: 0.93 (median 0.996); **m1*m2/r^2 and n*T/V recovered exactly (R2 1.000, 6 nodes)**. Log-space (log x -> log y): exact for pure power laws (1.000, 6 nodes) but catastrophic extrapolation when the law is not a power law (relativistic: R2 -1e39). Reason: centering (z=(x-mu)/sd) destroys multiplicative/ratio structure that symbolic search needs. **The preprocessing the TEACHER needs (scaling) is not the representation the SYMBOLIC search needs.** Consequence for the pipeline: surrogate search should be done in a representation chosen for symbolic discovery (raw / log / unit-aware), with the teacher's T composed *afterwards* purely for querying. T is therefore not a single object: T_teacher (for the NN) and T_search (for SR) -> a design principle and a likely contribution (H11).
F35. **H9 REFUTED**: GP on 5000 teacher queries is WORSE than GP on the 200 noisy labels (raw: in-range R2 0.82 vs 0.93; ex 0.66 vs 0.82) and produces larger formulas (e.g. newton_grav 53 vs 6 nodes). A teacher fitted on 200 noisy points is itself only R2 0.82 in-range; the surrogate inherits the teacher's errors and fits its artefacts (higher node counts). Distillation is bounded by teacher quality; it cannot add information (data-processing inequality), consistent with F10/F31.
F36. Where nothing works: Gaussian pdf (R2 0.5-0.65 for all SR variants, gplearn function set lacks exp), damped oscillation partly OK (0.89 raw). Function-set choice limits recoverable laws -> library/primitive choice (exp, pow) is part of the method.
Literature note: tree extrapolation failure is well known (see 01_LITERATURE round 2), so F3/F14 is a confirmation, not a discovery.
